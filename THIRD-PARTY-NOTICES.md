# Third-party data and software

DX Award Map's own code is MIT-licensed (see `LICENSE`). It uses and ships the following.

## Shipped with the program
| What | Source | Licence |
|---|---|---|
| d3 7.9.0 | https://d3js.org | ISC |
| topojson-client 3.1.0 | https://github.com/topojson/topojson-client | ISC |
| DXCC entities and primary administrative subdivisions | ADIF 3.1.6 enumerations, https://adif.org.uk | ADIF specification, free to use |
| DXCC entity positions and prefixes (`data/dxcc.json`) | AD1C country files, https://www.country-files.com | free to use, credit to AD1C |
| World, country and region maps | Natural Earth 1:50m and 1:10m, https://www.naturalearthdata.com | public domain |
| US states and counties (`packs/usa`) | us-atlas 3.0.1, https://github.com/topojson/us-atlas (US Census Bureau data) | ISC |

## Downloaded by the program from the official sources (not shipped)
These lists belong to their publishers. DX Award Map downloads them on first start and when you press
"Update award lists", and keeps a copy on your own PC (`%APPDATA%\DXAwardMap\packs`).

| Award | Source |
|---|---|
| JCC, JCG, KU (Japan) | JARL, https://www.jarl.org/English/4_Library/A-4-5_jcc-jcg/jcc-jcg.htm |
| RDA (Russia) | RDA award, https://rdaward.org |
| DOK and special DOKs (Germany) | DARC lists, via the mirror at https://www.df2et.de/cqrlog/ |
| URDA (Ukraine) | UARL, https://uarl.com.ua/urda/ |
